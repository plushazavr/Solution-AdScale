## Выводы 
Необходимо выбрать модульный монолит как фундамент, далее по паттерну Strangler Fig декомпозировать монолит. Однако рассмотреть вариант выноса в микросервис критичной для sla функции первым. 

### Промежуточное решение в горизонте 3 месяцев
1. Выделить hot path в отдельный сервис (с запросами DSP-площадки) c локальным кешем внутри сервиса, чтобы удержать SLA 80мс 
2. Разделить на модули в оставшемся монолите остальные функции
3. Добавить реплику БД для чтения для снятия тяжелых аналитических запросов с основной БД для аукциона. Плюс добавить кеш для БД.
4. Кроме реплики добавить автоматическое восстановление БД после недоступности


### Целевое решение в горизонте 1 года
1. Вынести остальные модули монолита в микросервисы по паттерну Strangler Fig
2. Внедрить асинхронные операции через брокер сообщений, для всех БД 
3. Разделить используемые данные по разным БД 
4. Внедрить мультирегиональное развертывание БД
