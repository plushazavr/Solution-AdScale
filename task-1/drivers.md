# Архитектурные драйверы

## Функциональные требования

1. Система принимает HTTP-запросы, определяет пользователей, подбирает кандидатов
2. Система проводит онлайн аукцион (RTB-аукцион).
3. Система применяет бизнес-правила для взвешивания ставок и определения победителя
4. Система отображает рекламу пользователям сайтов и приложений
5. Система регистрирует события показов и кликов
6. Система выполняет сбор аналитики
6. Система формирует отчетность
7. Система подбирает рекламу пользователям сайтов/приложений и выдаёт HTML/JS-разметку баннера
8. Система выполняет списание средств, выставление счетов и сведение балансов
9. Система предоставляет пользовательский интерфейс для рекламодателей для CRUD-операций

## Ограничения

### Технические ограничения

1. Стек: C++/Go/Python/Node.js. Гибридный монолит
2. Единственная БД - PostgreSQL
3. Один кластер, отсутствие контейнеризации, ручной деплой
4. Отсутствие кеша и очередей
5. Архитектура не задокументирована
6. Интеграция с DSP по OpenRTB/https

### Бизнес ограничения

1. Промежуточное решение через 3 месяца, целевое через год
2. Бюджет ограничен
3. Необходимость непреривность бизнеса при миграции
4. Штрафы DSP за деградацию latency и недоступность
5. Рост нагрузки: +20% сразу после интеграции, х2 через год
6. Штат 35 человек, нет выделенного SRE, техписателя, бизнес-аналитика
