# API Gateway для DSP-интеграции

B2B Gateway — единая точка входа для bid-запросов от DSP-партнёра. Принимает HTTPS/OpenRTB, выполняет маршрутизацию, аутентификацию, ограничение частоты запросов, circuit breaking, мониторинг времени отклика, маршрутизирует на Ad Server. 

1. **Маршрутизация:**
    * **GET /health** - HTTP, health-check
    * **POST /bid** - gRPS. Цель: Ad Server. Метод для отправки bid-запроса от партнера. Таймаут ответа по методу - 80 мс. 

2. **Адаптер.** Gateway должен выступить адаптером - преобразовать протокол взаимодействия между внешними клиентами и внутренними сервисами (openRTB->gRPC).

3. **Ограничение частоты запросов**. Выставить лимит по требованию партнера - 18 000 - 20 000 RPS (минимум 18 000 + запас)

4. **Аутентификация.** Необходимо настроить OAuth2.0

5. **Circuit breaker.** Настроить подсчет ошибок (5хх, 4хх) за 5-10 секунд, если порог ошибок за данный период времени более 50%, то цепь размыкается. 

6. **Мониторинг времени отклика.** Необходимо настроить логи (ELK): URL, метод, статус, partnerId, traceId. Настроить дашборд + алерты (Grafana): latency, RPS, количество ошибок (4xx, 5xx), срабатывание ограничения частоты запросов и circiut breaker.
