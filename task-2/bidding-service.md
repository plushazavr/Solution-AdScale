# Проектирование сервиса ставок (Bidding Service)

## Границы сервиса
Отвечает за приём запросов от Ad Server, взвешивание ставок, применение бизнес-правил, выбор победителя, запись победителя в кеш.

## API 
1. healthcheck 
2. Провести аукцион. 
**In-параметры:** requestId, userId, candidates[] (campaignId, ставка, таргетинг), context (geo, device)
**Out-параметры:** winner (campaignId, creativeId, price), reason (если нет победителя).

## Зависимости

| Зависимость             | Тип                | Зачем                             |
| ----------------------- | ------------------ | --------------------------------- |
| Ad Server               | синхронная (gRPC)  | получает кандидатов               |
| Redis `Кеш кампаний`    | синхронная         | данные кампаний/ставок            |
| Redis `Кеш балансов`    | синхронная         | проверка бюджета                  |
| Redis `Кеш победителей` | синхронная (write) | сохранить победителя для Delivery |
| Delivery Service        | синхронная (gRPC)  | передать победителя               |

## Модель данных

### Модель "кампания"

```javascript
Campaign {
  campaignId //идентификатор кампании
  advertiserId //идентификатор рекламодателя 
  bid          //ставка
  targeting    //таргетинг (geo, device)
  ...
}
```

### Модель "баланс"

```javascript
Balance {
  advertiserId //идентификатор рекламодателя
  availableAmount //доступный бюджет
  ...
}
```

### Модель «победитель»

```javascript
Winner {
  requestId //идентификатор запроса
  campaignId //идентификатор кампании  
  price //цена
  advertiserId //идентификатор рекламодателя
  ...
}
```
